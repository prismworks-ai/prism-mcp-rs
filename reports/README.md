# Reports

This directory contains a small number of tracked snapshots plus reports generated by local or hosted CI. Every report is time-sensitive and must identify its generation date and environment.

| Report | Source | Interpretation |
|--------|--------|----------------|
| `benchmark-report.md` | `scripts/ci/run-benchmarks.sh` or a recorded manual run | Development/CI snapshot, not an SLA |
| `coverage-report.md` | `scripts/ci/generate-coverage-report.sh` | Snapshot for a specific LCOV run |
| `security/summary-*.md` | `scripts/security-audit.sh` | Historical audit record, not current vulnerability status |

Generate current results locally:

```bash
./scripts/ci/run-benchmarks.sh
cargo llvm-cov --all-features --workspace --lcov --output-path lcov.info
./scripts/ci/generate-coverage-report.sh
./scripts/security-audit.sh
```

Detailed Criterion and HTML coverage output lives under ignored `target/` paths. GitHub Actions may upload reports and raw data as run artifacts with limited retention.

Do not cite a checked-in report as the current state of another commit, machine, feature set, or dependency graph. For release decisions, regenerate it from the exact candidate and record the command/toolchain.
