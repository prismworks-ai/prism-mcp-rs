# Reports Directory

This directory is for CI/CD generated reports that are uploaded as artifacts.

## Report Types

### Coverage Report
- Generated by `cargo llvm-cov` in CI
- Uploaded as GitHub Actions artifact
- Available for download from workflow runs
- Not committed back to repository

### Benchmark Report
- Generated by benchmark suite in CI
- Uploaded as GitHub Actions artifact
- Available for download from workflow runs
- Not committed back to repository

### Documentation Examples Coverage
- Generated by documentation validation tests
- Uploaded as GitHub Actions artifact
- Available for download from workflow runs
- Not committed back to repository

## Accessing Reports

1. Go to the [Actions tab](https://github.com/prismworks-ai/prism-mcp-rs/actions)
2. Click on a workflow run
3. Download artifacts from the "Artifacts" section

## Local Generation

To generate reports locally:

```bash
# Coverage report
make coverage
# Report will be in .local/coverage/

# Benchmark report
cargo bench
# Results will be in target/criterion/

# Documentation examples
make examples-validate
# Report will be in examples/validation_report.md
```

## Note

Reports are no longer automatically committed to the repository. This prevents:
- Repository bloat from frequent report updates
- Unnecessary commit noise
- CI/CD permission issues
- Merge conflicts from automated commits

All reports are available as CI artifacts for review when needed.
